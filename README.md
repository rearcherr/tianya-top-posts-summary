# 天涯顶级神帖 · 观点总结与脉络分析

对 2005–2019 年天涯论坛经典长帖的逐篇观点提炼与横向主题分析。共 **197 篇**，覆盖房地产/宏观经济、股市投资、社会观察、灵异悬疑、文学小说等 14 个类别。

所有内容均由自动化流程提取正文后逐篇精读产出，**观点均转述自原作者**，仅作资料整理之用。

## 内容结构

每篇总结包含 6 个字段：

- **分类** — 14 类之一
- **一句话核心** — 20–45 字概括作者核心主张
- **主要观点** — 3–6 条具体主张（带数字、机制、可操作建议）
- **关键论据/数据** — 文中出现的数字、事件、案例
- **金句** — 原文最有冲击力的句子
- **立场/可信度** — 对作者论证质量的评估

## 核心发现

房地产 + 宏观经济合计占 **35.5%**，是这批帖子的绝对主线。同一个命题被反复推演了 14 年：

- **2005–2009** — 加息与调控能否压住房价，「调控只会制造上涨的喷泉」
- **2010–2014** — 调控累积效应与「调控原罪」的反思
- **2015–2019** — 货币宽松、涨价去库存、汇率破 7、牛熊切换

作者多为一线从业者（地产中介、银行审计、检察官、DNA 鉴定师、期货操盘手），普遍以「亲身经历担保可信度」，并习惯用租售比、杠杆倍数、M2/GDP、土地一级开发成本等自造指标拆解政策意图。

### 预测验证

分析报告从帖文中抽出 **21 条写明年份与目标价位的判断**做事后比对：

| 结果 | 条数 |
|---|---:|
| 完全兑现 | 8 |
| 部分兑现 | 6 |
| 落空 | 7 |

**方向性判断的命中率明显高于点位判断** —— 这是这批帖子最值得警示的地方。

## 处理流程

```
原始压缩包 (rar/zip, PDF 为主)
  │
  ├─ extract_text.py    批量解压 + pdfplumber 提取正文
  │                     （每文件取样上限 60 页 / 9 万字符，多进程 8 并发）
  │
  ├─ fix_doc.py         修复 Word 97-2003 二进制文档
  │                     解析 FIB → CLX piece table 抽取正文
  │                     常规方式会解出乱码，非标准 .doc 必须走这条路
  │
  ├─ SPEC.md            总结规格说明（统一格式与分类枚举）
  │                     按此规格分批并行精读，每批 6–8 篇
  │
  └─ build_html.py      解析 Markdown → 结构化 JSON → 生成可筛选 HTML
```

脚本中硬编码了本地 Windows 路径，若在其他环境复现需自行修改 `ROOT` / `OUT` / `OUTDIR` 常量。
