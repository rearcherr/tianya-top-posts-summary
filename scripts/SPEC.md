# 天涯神帖批量总结 · 统一规格说明

## 任务
对早期天涯论坛经典长帖的正文文本，逐篇提炼核心观点，输出结构化中文摘要。

## 输入
- 文本目录：`C:\Users\rearcher\WorkBuddy\2026-10-07-19-03-52\tianya\text\`
- 你的批次清单：`C:\Users\rearcher\WorkBuddy\2026-10-07-19-03-52\tianya\batches\batchNN.json`
  （字段：`file` 纯文件名；`part`/`parts` 表示该文件被切成几片、当前是第几片。同一 file 出现多次时parts > 1，需合并多片后再总结）

## 读取方式
文本可能很大。对每个条目：
- 文件 < 300KB：用 Read 工具一次性读完（offset/limit 可控）
- 文件 > 300KB：先 Read 前 1200 行，再用 Bash 的 `sed -n '1200,2600p'` 等分段读取，总共读 3-5 段，覆盖约 6000-10000 行即可，足以把握全文论点。**不要**试图读完每一个字，抓主干和转折。

## 输出格式（严格遵守）
写入文件：`C:\Users\rearcher\WorkBuddy\2026-10-07-19-03-52\tianya\summary\batchNN.md`

对批次内**每一个** file 输出一节，格式如下（parts>1 的文件只输出一节）：

```
## N. 《原标题》

- **分类**：从下面枚举中选一个
- **一句话核心**：20-45 字，概括作者最核心的主张或结论
- **主要观点**：
  1. …（3-6 条，每条 25-60 字，要具体：有数字、有机制、有具体建议就写出来，不要空泛）
  2. …
- **关键论据/数据**：文中出现的关键数字、事件、案例（2-4 条，没有就写"文中无明确数据，主要为逻辑推演"）
- **金句**：摘 1-2 句原文中最有冲击力的句子（加引号）
- **立场/可信度**：一句话，例如"强烈的看多楼市预言，立场鲜明但缺乏实证" / "纪实文学，无明确观点" / "学术性考据"
```

### 分类枚举（必须用其中之一）
房地产/楼市 · 宏观经济/金融 · 股市/投资 · 商业/营销 · 职场/个人成长 · 历史/军事 · 国际关系/地缘 · 政治/体制 · 社会观察/阶层 · 玄学/命理/中医 · 灵异/悬疑 · 文学/小说 · 哲学/方法论 · 其他

## 质量要求
1. **必须读完该条目对应的文本再总结**，不要仅凭标题臆测。
2. 观点要抓作者自己的判断和主张，不要写成内容简介或读后感。
3. 金融/房产类帖子常有时间背景，请注明作者的判断年份（如"作者判断2015年前后"），这对判断有效性很重要。
4. 同一批次内相邻帖子主题可能重复（如多篇楼市预测），要各自独立总结，差异点要写出来。
5. 不评价观点对错，只做忠实提炼；如需提示，可在"立场/可信度"里一句带过。
6. 若某条目 parts>1，必须把各片内容都覆盖后再写总结。

## 最后
在文件末尾不要写额外说明。完成后回复一句"batchNN 完成，共N 篇"即可。
